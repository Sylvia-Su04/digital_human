九、已知问题与建议
------------------------------------------------------------
  1. GPT-SoVITS 模型加载较慢 (~2.5min)，建议生产时用 API 模式常驻服务
     (api.py -p 9880)，避免每次推理重新加载模型
  2. 4GB 显存下 GPT-SoVITS 推理峰值 94%，接近 OOM，建议关闭其他 GPU 程序
  3. SadTalker 输出视频在 custom_nodes 目录下，建议后续 workflow 增加
     VHS_VideoCombine 节点直接输出到 ComfyUI/output 目录
  4. 当前 role_voice.wav 为 101KB（约1.6秒@32kHz），文案较长时文件会更大
